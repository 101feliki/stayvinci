# Developer tools

| Script                 | What it does                                                                                                                                             |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `brand/build-logos.py` | Rebuilds the bold, transparent logo and SV mark (dark and light versions) from the Figma export in `brand/logo/stayvinci-logo-figma.svg`.                |
| `qa/drive-browser.mjs` | Opens the apps in headless Edge or Chrome, clicks and types, switches light/dark, and saves screenshots to `.qa-output/`. Handy for checking UI changes. |
